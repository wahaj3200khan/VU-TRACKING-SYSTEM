# 🎓 VU Tracking System

> A console-based academic management application developed in C++ using Object-Oriented Programming (OOP) principles and File I/O.

---

## 📌 Overview
The **VU Tracking System** is designed to streamline academic administrative tasks. It allows users to register student batches, track quiz records, and manage student academic performance efficiently using persistent local file storage.

---

## ✨ Features
* 👤 **Student Registration:** Add, manage, and view student records.
* 📝 **Quiz & Marks Management:** Log quiz scores and track individual student performance.
* 💾 **Data Persistence:** Store and retrieve records smoothly using C++ File I/O (`students.txt`, `quiz_records.txt`).
* 📊 **Academic Analytics:** Generate academic summaries for registered batches.

---

## 🛠️ Tech Stack
* **Language:** C++
* **Concepts:** Object-Oriented Programming (OOP), File Handling (I/O)
* **Storage:** Local File Storage (`.txt`)

---

## 🚀 How to Run Locally

Navigate to the project directory:
cd VU-TRACKING-SYSTEM

Compile the source code:
g++ "Oops project final.cpp" -o app

Run the application:
./app
